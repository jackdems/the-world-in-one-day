## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program is Node 22, standard library only: it verifies `entry.png` (PNG magic bytes,
1 MiB cap) and writes it to the output directory, unchanged, every run.
